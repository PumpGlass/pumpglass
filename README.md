# PumpGlass

PumpGlass is a free crypto futures analytics platform: liquidation heatmaps for every pair, real order book liquidity, whale positions against the crowd, futures charts and a live pump scanner.

Website: [pumpglass.com](https://pumpglass.com)

![Liquidation heatmap with the real order book](https://pumpglass.com/smart-money/static/og/og-heat.png)

## Tools

## Data

- Source: Binance USDT-M perpetual futures, including gold, silver, oil and tokenized stocks.
- Liquidation levels are an estimate from open interest changes and common leverage, not real orders. The order book layer shows real resting limit orders.
- Whales are the largest consistently profitable traders on each pair, tracked as a group.
- PumpGlass shows market data. It does not predict prices and is not financial advice.
